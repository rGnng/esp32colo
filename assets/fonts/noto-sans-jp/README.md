# Playback font

Source: Noto Sans JP Regular 2.004 (SIL OFL 1.1), unmodified upstream font:
https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf

Copyright 2014–2021 Adobe, with Reserved Font Name Source. The complete upstream
license is in LICENSE; the source hash and raster format are in manifest.json.
The optional generator rasterizes all 16,732 mapped characters at 16 px with
4-bit antialiasing. Japanese kanji/kana, Latin and supported CJK extensions are
retained. Unsupported characters use `?`; Korean/emoji coverage is not promised.
Normal builds use the generated flash data without Python font packages or
network access. Glyph lookup/rendering copies no whole-font tables into RAM.
