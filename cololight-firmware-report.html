04

How to enter flash mode

For this reference design, hold two buttons: REC_KEY and the centre knob.

The small-board S1 / REC_KEY grounds GPIO0. The knob push button EKEY grounds GPIO46, which has an external pull-up. Espressif requires GPIO0 low and GPIO46 low or floating at reset to enter the ROM download mode.

  1. Fully remove power.Disconnect USB and, if fitted, the battery so the ESP32 actually powers off. USB replugging alone may not reset a battery-powered unit.
  2. Press and hold both controls.Hold the small-board S1 / REC_KEY button and press down the centre rotary knob at the same time.
  3. Reconnect USB while holding both.Use a USB data cable. Keep both controls pressed during power-up, then release them after about one second.
  4. Check for a new USB device or serial port.On Linux, inspect the commands below. A serial port may appear as /dev/ttyACM0; the exact name depends on the host and USB interface.
lsusb
ls -l /dev/serial/by-id/ /dev/ttyACM* /dev/ttyUSB*

Missing-path messages from the second command simply mean those ports are absent. S2 / OPEN_KEY is wired to GPIO15. Button labels and the board revision must match the drawings before applying this procedure.

Basis: main-board module wiring, power-board S1/S2 wiring, screen-adapter EKEY pull-up and switch, and Espressif boot-mode requirements. This combined procedure is an inference from those sources and has not been tested on your unit.

06

A practical route to a working firmware

  1. Identify the physical board.Confirm its module marking and revision; compare the USB, buttons, and display wiring with the reference drawings.
  2. Establish download access and preserve the original.Identify the chip and flash capacity, inspect security status without changing it, and read a full factory backup if permitted. Save a checksum and existing partition layout before any write.
  3. Define the functions and build a small first version.Set up the ESP32-S3 toolchain. Start with USB diagnostics and input checks; confirm the display controller before adding its driver. Add the agreed keypad, media, clock, or other functions incrementally.
  4. Flash and verify on the identified unit.Use the generated bootloader, partition table, and application offsets for that build. Verify the written image, then test boot, USB, buttons, knob, and each implemented feature.

A backup read can be restricted by device security settings. No claim of a recoverable backup or a usable flash interface can be made until the unit is connected and inspected. Flash read/write commands and verification are documented in Espressif's esptool guide.
